# Acid 303

## Objetivo

Tener una voz de bajo con el carácter del TB-303 sin agregar dependencias ni
romper la regla de capas: sierra/cuadrada, filtro resonante con envolvente,
glide entre notas y **acento/slide por paso**. No es una emulación circuito a
circuito: es un mono-sinte del motor existente con la articulación del 303.

## Alcance

Dentro:

- Machine preset `acid-303` y sound preset `acid-303`.
- `MachineConfig.glide` para voces mono.
- `PatternState.accents` y `PatternState.slides`: arrays de 0/1 por track.
- `SoundEvent` de synth con `accent` y `slide`.
- UI de dinámica por paso para accent y slide.
- Persistencia en clips, escenas, sesiones y presets.

Fuera:

- Emulación del filtro diode ladder del 303 original.
- Acento por paso sobre la resonancia (el acento abre cutoff y sube nivel).
- Slide polifónico: sólo aplica a la voz mono.

## Modelo

```ts
// domain/pattern.ts
readonly accents: Record<string, StepValues>; // 0/1
readonly slides: Record<string, StepValues>;  // 0/1

// domain/graph.ts — MachineConfig
readonly glide?: number; // segundos

// domain/audio.ts — SoundEvent synth
readonly accent?: boolean;
readonly slide?: boolean;
```

El preset por defecto:

```ts
{
  kind: 'mono',
  oscillator: 'sawtooth',
  envelope: { attack: 0.003, decay: 0.18, sustain: 0.05, release: 0.09 },
  filter: { frequency: 420, q: 14 },
  filterEnvelope: {
    octaves: 3.2, attack: 0.002, decay: 0.22, sustain: 0.05, release: 0.12
  },
  glide: 0.06
}
```

## Implementación

- `playback.ts`: si el track `bass` tiene máquina de synth, dispara `type:
  'synth'` en vez de sample; adjunta `accent`/`slide` leídos del paso.
- `modular-audio-engine.ts`:
  - `portamento = slide ? glide : 0` antes del trigger.
  - Acento: `velocity × 1.35` y un `Tone.Signal` de cutoff conectado al filtro
    del mono, con `setValueAtTime(+1800 Hz, event.time)` y retorno a 0 en
    `event.time + 0.12`; todo con tiempos del evento.
- UI: `Accent` y `Slide` en el bloque Dinámica del secuenciador, y lectura en el
  resumen del paso.

## Riesgos

| riesgo | mitigación |
|---|---|
| El acento se agenda con reloj real | `Tone.Signal` con `setValueAtTime(event.time)` |
| El glide se aplica a notas que no corresponde | sólo `slide` del paso, `portamento` se resetea a 0 |
| Sesiones viejas sin accents/slides | se leen como 0 y el render no cambia |
| El 303 no es idéntico al original | documentado: es un mono-serie del motor, no DSP del 303 |

## Nota de performance

Se probó una voz 303 en AudioWorklet contra `Tone.MonoSynth`. Para una sola voz
el worklet no gana en CPU (231 ms vs 238 ms en 128 notas); el límite actual está
en la mutación del grafo y el hilo principal, no en el DSP nativo. El prototipo
queda en `docs/performance.md` como evaluación, no como reemplazo del preset.

## Criterio de salida medible

- Dos pasos consecutivos con slide suenan ligados; sin slide, atacan de nuevo.
- Un paso con accent se oye más fuerte y con más apertura de filtro que el mismo
  paso sin accent.
- `test:audio` sigue determinista y sin clipping.
